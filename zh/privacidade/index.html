隐私政策

最后更新：2026 年 11 月 10 日

摘要：Mosaica 不收集、不在服务器上存储，也不共享你的任何个人数据。没有广告、跟踪、分析，也无需注册。

我们是谁

Mosaica 是由 ATOS PRODUÇÕES（以下称“我们”）开发的游戏。本政策适用于 iPhone、iPad 和 Android 上的 Mosaica 应用、浏览器版本以及本网站。

应用保存的数据

为了让游戏正常运行，应用会在你的设备上（网页版则在浏览器中）保存：进行中的对局、你的记录、已阅读的部族故事，以及语言、难度和教程等偏好设置。这些信息不会离开设备，也不会发送给我们。删除应用或清除网站数据时，它们会被删除。

我们收集的数据

没有。应用不会要求你提供姓名、邮箱、位置、通讯录、照片或任何其他个人信息，也不使用广告标识符。我们不使用任何第三方分析、跟踪或广告工具，本网站也不使用 Cookie。

Game Center（iPhone 和 iPad）

如果你登录了 Game Center，应用会将你的分数和已解锁的成就发送到由 Apple 运营的 Game Center 服务。我们不会获得你的邮箱、Apple 账户或其他账户数据，只能看到 Apple 在排行榜上公开显示的内容，例如你选择的昵称。Game Center 受 Apple 隐私政策约束。你可以随时在设备设置中退出 Game Center。

网站托管

本网站托管于 GitHub Pages。与所有网络服务器一样，GitHub 可能出于安全和服务运行目的记录 IP 地址等技术访问数据，详见 GitHub 隐私声明。我们无法访问这些记录。

邮件联系

如果你给支持团队写信，我们仅会使用你的邮箱地址和信息来回复你，不会与任何人共享，并会在不再需要时删除。

儿童

由于我们不收集个人数据，任何年龄的人都可以使用 Mosaica，而不会有任何信息被收集。

你的权利（GDPR 与 LGPD）

我们的系统中不保存任何个人数据，因此我们这边没有可供查阅、更正或删除的数据。如有任何疑问，请通过下方邮箱联系我们。

政策变更

本政策如有更新，将在本页面发布并注明新的日期。
